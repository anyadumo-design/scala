# SCALA — сайт ательє штор (Київ)

Редизайн сайту [scalahome.com.ua](https://scalahome.com.ua). Репозиторій
для ревізії: тут і готовий до перегляду статичний сайт, і тема WordPress,
у яку його перенесено.

## Що подивитися насамперед

Відкрийте `index.html` у браузері — усе працює без сервера й без збірки.

| Сторінка | Файл |
|---|---|
| Головна | `index.html` |
| Каталог | `catalog.html` |
| Про бренд | `about.html` |
| Контакти | `contacts.html` |

Головний прийом сайту — hero, у якому штори розсуваються під час прокрутки.
На телефоні дистанція коротша: один свайп замість півтора екрана.

## Структура

```
scala-site/
├── index.html            головна (лендинг)
├── catalog.html          каталог: види штор, тканини, комплектація
├── about.html            про бренд
├── contacts.html         контакти + форма
├── vydy-shtor/           8 сторінок видів штор
├── assets/
│   ├── css/main.css      уся дизайн-система одним файлом
│   ├── js/main.js        інтерактив без залежностей
│   └── img/              фото у WebP, по дві роздільності
├── tools/
│   ├── add-photo.py      готує фото з _source-photos/ у WebP
│   ├── build-reviews.py  збирає плитки скріншотів із _source-reviews/
│   └── sync-theme.py     переносить CSS і JS у тему
└── wp-theme/
    └── scala-atelier/    тема WordPress
```

## Збірка

Кроків збірки немає — HTML відкривається як є. Два скрипти обслуговують
те, що інакше довелося б робити руками:

```bash
# після будь-якої правки assets/css/main.css або assets/js/main.js
python3 tools/sync-theme.py
```

Тема має власну копію стилів і скрипта: вона мусить працювати сама,
без зовнішніх залежностей. Писати їх двічі неможливо — копії розходяться
непомітно. Тому джерело одне, `assets/` у корені, а тема отримує копію.
`--check` покаже розбіжність, нічого не змінюючи.

```bash
# після додавання скріншотів відгуків у _source-reviews/
python3 tools/build-reviews.py
```

Робить із кожного скріна мініатюру й повний кадр у WebP і перезбирає
плитки в `index.html`. Вихідні файли в репозиторій не йдуть.

```bash
# нове фото для сайту
python3 tools/add-photo.py request-photo
```

Кладе в `_source-photos/` фото, а скрипт робить із нього два WebP —
повний і `@0.5x` для srcset, — копіює в тему й друкує готовий тег `<img>`.

## Тема WordPress

Самостійна тема, не пов'язана з чинною темою `scala`. Встановлюється
як звичайна тема; після активації сама створює сторінки, переносить
фото в медіабібліотеку, збирає меню й наповнює розділи демоконтентом.

В адмінці з'являється розділ **SCALA**:

- **Налаштування** — 7 вкладок: контакти, головний екран, заголовки
  секцій, списки, форма, внутрішні сторінки;
- **Види штор**, **Тканини**, **Проєкти**, **Комплектація**,
  **Відгуки**, **Питання**, **Instagram** — окремі розділи;
- **Заявки** — звернення з форми з позначкою, з якої кнопки вони прийшли.

Вимоги: WordPress 6.4+, PHP 8.0+. Сторонні плагіни не потрібні.

## Контент

Тканини (21 позиція) перенесені з чинного сайту клієнта разом з описами
та фото. Фотографії інтер'єрів — реальні проєкти клієнта, покращені.

Скріншоти відгуків (11 переписок) — реальні звернення клієнтів. У сітці
показуються шість, решта відкривається в перегляді на весь екран. Обидві
текстові цитати взяті з цих же переписок: нічого не переписано, лише
зведено в один абзац і розставлено розділові знаки. Підписи знеособлені —
роль і обсяг роботи, без імен і нікнеймів.

Що ще чекає на матеріали клієнта: адреса шоуруму й графік роботи,
фото цеху.
